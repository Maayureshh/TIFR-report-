# TIFR Internship Report — GitHub Description

A short report documenting my internship experience at the Tata Institute of Fundamental Research (TIFR), Mumbai. The work involved contributing to a scientific Data Acquisition (DAQ) system, debugging data-handling issues, and improving the reliability of the software used for detector data collection and monitoring.

The report provides a brief overview of the project, technical work performed, challenges encountered, and the outcomes of the internship.
